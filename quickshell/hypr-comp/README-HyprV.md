# hypr-comp HyprV install

This is an isolated Quickshell port of `ilyamiro/hypr-comp`.

- Start: `~/.config/HyprV/quickshell/hypr-comp/scripts/launch.sh`
- Stop: `~/.config/HyprV/quickshell/hypr-comp/scripts/stop.sh`
- Toggle launcher: `~/.config/HyprV/quickshell/hypr-comp/scripts/qs_manager.sh toggle applauncher`

It does not modify Hyprland `exec-once` or replace the existing HyprV Quickshell config.
